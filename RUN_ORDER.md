# Step 1 run order

## A. Reproduce the bundled offline bootstrap

```bash
cd NKG2A_ectodomain_project
make step1-offline
```

This is safe on a CPU-only computer and requires no network connection or third-party Python package.

Review:

- `09_results/qc/sequence_qc.tsv`
- `09_results/tables/source_sequence_comparison.tsv`
- `09_results/tables/source_sequence_differences.tsv`
- `00_admin/PROJECT_STATUS.md`

## B. Collect current database records

On an internet-connected machine:

```bash
export NCBI_EMAIL='your.name@institution.edu'
make step1-online
```

Review these first:

- `09_results/qc/fetch_status.tsv`
- `09_results/qc/ncbi_candidate_search_status.tsv`
- `09_results/tables/ncbi_candidate_hits.tsv`
- `09_results/qc/structure_download_status.tsv`

## C. Manually curate unresolved records

For each candidate, record:

- exact accession and version
- source database and retrieval date
- species and taxonomic ID
- gene/locus assignment
- NKG2A versus NKG2C evidence
- NKG2C paralog number, if supported
- transcript/splice-form evidence
- protein completeness
- ectodomain-boundary evidence
- synteny or genomic-neighborhood evidence
- reason for inclusion or exclusion

Update `03_metadata/sequence_manifest.tsv`; never edit downloaded raw FASTA in place.

## D. Rebuild outputs after metadata changes

```bash
make validate
make ectodomains
make identity
make compare
make test
make manifest
```

## E. Produce the final multiple-sequence alignment

Create the optional environment and run MAFFT:

```bash
conda env create -f environment-curation.yml
conda activate nkg2a-curation
make alignment
```

The pairwise identity matrices generated by the bootstrap are only preliminary QC statistics. Recalculate final identities from the reviewed MSA.

## F. Package the workspace

```bash
make package
```

## G. Defer RFantibody until target and off-target structures are accepted

```bash
make rfantibody-later
```
